# electronic-diary2
Функции проекта , в этом проекте я реализовал : имитацию электронного дневника, использовав эти пункты меню вы можете посмотреть: 
1. Показать оценки по каждому предмету
2. Общий балл всех оценок
3. Узнать самый низкий и максимальный балл



Перед использованием заполнить файл "directory.txt"
